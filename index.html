📌 Formatting Rules

  • # Title = Heading
  • ## Title = Subheading
  • 1. text = Numbered list
  • - text ya * text = Bullet point
  • Chhoti ALL CAPS line = Heading (apne aap)
  • Chhoti line jo : par khatam ho = Subheading (apne aap)
  • Khaali line = Paragraph gap
